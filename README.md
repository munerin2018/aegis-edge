# Aegis Edge

**Aegis Edge は、[Aegis Authenticator](https://github.com/beemdevelopment/Aegis) をもとにした非公式の Android 向け二段階認証アプリの改造版です。** 他のアプリを開いたまま認証コードを確認できる、画面端のショートカットを追加しています。Aegis の開発元による公式版ではありません。

## 主な追加機能

- 画面右端に、半分だけ見える半透明のアイコンを表示します。
- アイコンをタップするか画面の内側にスワイプすると、同じアイコンがせり出します。もう一度タップすると認証コード一覧を開きます。
- 一覧でコードを選んでコピーできます。保管庫がロックされている場合は、既存の解除操作が必要です。
- 長押ししてドラッグすると、アイコンを左右の端の好きな高さに移動できます。移動中に画面上部の「×」へ重ねて離すと終了します。アプリ内の開始・終了メニューからも切り替えられます。
- アイコンを画面の外側へスワイプすると、半透明の細い縁だけを表示します。その縁をタップするか画面の内側にスワイプすると、アイコンを再び表示します。使用には Android の「他のアプリの上に表示」の許可が必要です。
- Android の自動入力機能を試験的に追加しています。対応するワンタイムコード入力欄を対象に、サービス名とサイト名・アプリの識別子の一致を手がかりに候補を表示します。

## 現在の状態

**実験段階です。** 自動入力のエンドツーエンド動作と、サイト・アプリの正当性の自動検証は完了していません。自動入力を選ぶと、端末で利用する自動入力サービスが切り替わる場合があります。すべてのサイトやアプリで候補が出るわけではありません。入力先を必ず確認してください。

認証情報を扱うアプリのため、利用前に元の Aegis の手順に従い、復元できる安全なバックアップを保管してください。変更部分は独立したセキュリティ監査を受けていません。

Pixel 7a では、画面端のアイコンから一覧を開く操作を確認しています。自動入力の完全な動作確認は未実施です。既存の単体テストは 27 件中 22 件が成功し、5 件はテスト実行環境の Java のバージョンが不足したため実行できませんでした。

## ビルド

Android SDK 36 と Java 17 以上、Git を用意し、リポジトリのルートで次を実行してください。

```sh
./gradlew :app:assembleDebug
```

Windows では `gradlew.bat :app:assembleDebug` を実行します。デバッグ版は元のアプリとは別の ID でインストールされ、データも別管理です。リリース設定のアプリ ID は元の Aegis と同じため、公式版を上書きできるとは限りません。署名や配布用の設定はまだ整えていません。デバッグ版から本番データへ移行する前にバックアップと復元方法を確認してください。
